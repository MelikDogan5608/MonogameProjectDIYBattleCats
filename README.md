Introduction :
Our game is a tower defense game where the player competes against an computer-controlled opponent rather than a real person. 
Both the player and the opponent have their own troops. The player's objective is to defend their own tower while destroying the enemy's tower. 
If the player successfully destroys the opponent's tower, they complete the level and progress to the next one. The game is successfully beaten when the player completes the fifth and final level. 
Our game is inspired by Battle Cats.
How to Play:
When the game opens, clicking the "Play" button on the initial start screen (Main Menu) redirects the player to the "Planning Room". 
Inside the Planning Room, clicking the "Map" button takes the player to the Map Screen, which grants access to the levels. 
Once a level is selected, the game begins. During gameplay, pressing the "1" key summons a troop, which then and it immediately advances to attack.
